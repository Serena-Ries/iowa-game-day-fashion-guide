# A/B Test Plan

## 1. Page and Element Being Tested

The test will be conducted on the homepage of the Iowa Game-Day Fashion Guide. The single element being changed is the homepage subtitle.

**Version A (Current):**
"Your guide to black, gold, and game-day style."

**Version B (New):**
"Find the perfect Iowa outfit for every kind of game day."

All other homepage content will remain the same. Version A will use the current homepage, and Version B will contain only the new subtitle.

## 2. Hypothesis and Reasoning

I predict that Version B will receive a higher percentage of YES responses than Version A. Version B communicates a more specific benefit by explaining that visitors can find an outfit for every kind of game day. I believe this wording will make the purpose of the website clearer and encourage visitors to use the guide.

## 3. Model, Persona, Prompt, and Assignment

**Model:** ChatGPT (GPT-6). The same model and settings will be used for every trial.

**Persona:** A woman in her 20s–50s who is looking for an outfit to wear to an Iowa football game.

**Prompt:** The same prompt will be used for every trial, with only the homepage version changing:

"You are a woman in your 20s–50s looking for an outfit to wear to an Iowa football game. Review the homepage content below as if you were visiting the website. Would you use this guide to help choose your game-day outfit? Answer YES or NO, followed by one sentence explaining your decision.

[Insert the full homepage content for the assigned version here.]"

The full homepage content will be provided in the same format for every trial. Each trial will take place in a fresh conversation with memory turned off so that previous trials do not influence later responses.

Before collecting results, 50 trials will be randomly assigned to Version A and 50 trials to Version B. The assignment will be recorded before each trial is conducted.

## 4. Primary Outcome

The primary outcome will be whether the AI visitor answers YES or NO to the same question in every trial.

- YES = 1
- NO = 0

The percentage of YES responses will be calculated separately for Version A and Version B.

## 5. Sample Size, Completion Date, and Comparison

The test will include 100 total trials, with 50 trials for Version A and 50 trials for Version B. I plan to complete all 100 trials by November 30, 2026.

I will compare the percentage of YES responses for each version and calculate the difference between them. A higher percentage of YES responses for Version B would support my hypothesis. I will also use a statistical test to evaluate whether the difference could be due to chance.
